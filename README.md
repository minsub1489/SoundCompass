# SoundCompass 테스트 게임

SoundCompass가 실제 게임 플레이에 도움이 되는지 확인하기 위한 3인칭 교전 웹 게임입니다.

SoundCompass는 소리를 들을 수 없는 플레이어에게 소리의 방향과 종류를 화면으로 알려 주는 시스템이며, 이 게임 밖에서 독립적으로 동작합니다. 이 게임은 시각화를 하지 않고, 실제 슈팅 게임처럼 소리만 냅니다. SoundCompass는 컴퓨터의 소리 출력을 받아 분석하고 표시합니다.

- 설계 문서: [docs/superpowers/specs/2026-11-25-soundcompass-testbed-design.md](docs/superpowers/specs/2026-11-25-soundcompass-testbed-design.md)
- 구현 계획: [docs/superpowers/plans/2026-11-25-soundcompass-testbed.md](docs/superpowers/plans/2026-11-25-soundcompass-testbed.md)

## 빠른 시작

최신 Chrome에서 실행합니다. 인터넷 연결은 필요하지 않습니다. `index.html`을 파일로 직접 열면 음원을 불러오지 못하므로, 반드시 로컬 서버로 엽니다.

**Node가 설치된 PC** (이 폴더에서 실행):

```powershell
npm install
npm run build
npm run preview
```

**빌드된 `dist` 폴더만 옮긴 PC** (Python이 있는 경우, `dist` 폴더에서 실행):

```powershell
python -m http.server 8080
```

서버를 띄운 뒤 Chrome에서 표시된 주소(예: `http://localhost:8080`)를 엽니다.

## 실험 진행

### 진행 순서

1. 시작 화면에 참가자 ID와 조건 이름을 입력하고, 맵과 출력 방식을 고른 뒤 시작합니다.
2. 연습장을 한 번 플레이합니다(90초). 조작과 규칙을 익히는 단계이며, 결과는 저장하지 않습니다.
3. 본 맵 3개를 3분씩 플레이합니다. 맵과 조건의 짝은 참가자마다 라틴 방격으로 바꾸고, 배정표는 실험 진행자가 관리합니다.
4. 라운드가 끝날 때마다 결과 화면이 뜨고 CSV가 저장됩니다. "다음"을 누르면 시작 화면으로 돌아갑니다.

### 비교 조건

| 조건 | 참가자가 소리를 듣는가 | SoundCompass |
| --- | --- | --- |
| 소리 끔 (기준선) | 듣지 않음 | 끔 |
| 소리 끔 + 시스템 (핵심 조건) | 듣지 않음 | 켬 |
| 소리 켬 (상한선) | 들음 | 끔 |

조건 이름은 시작 화면에 자유롭게 입력하며, 입력한 값이 CSV에 그대로 기록됩니다. 게임은 조건을 직접 바꾸지 않습니다.

> **주의: "소리 끔"은 게임 음량을 끄는 것이 아닙니다.**
> 게임 음량을 끄거나 Windows 출력을 음소거하면 SoundCompass가 받을 입력도 함께 사라집니다. 게임 소리는 그대로 출력하고, 참가자가 소리를 듣지 못하게 하는 방식(예: 헤드폰을 쓰지 않음)으로 조건을 만듭니다. 그래서 게임에는 실험용 음소거 기능이 없습니다.

## 게임 규칙

### 목표와 조작

맵 곳곳의 노란 보급 상자를 최대한 많이 모으는 것이 목표입니다. 상자를 하나 주우면 다른 곳에 새 상자가 생기므로 3분 내내 계속 움직여야 하고, 그동안 적 봇 4명이 다가옵니다. 체력이 0이 되면 출발 지점에서 바로 다시 살아나며, 모은 상자 수는 줄지 않습니다.

| 키 | 동작 |
| --- | --- |
| W A S D | 이동 |
| Shift | 달리기 |
| Space | 점프 |
| 마우스 | 시점 회전, 조준 |
| 왼쪽 클릭 | 사격(누르고 있으면 연사) |
| R | 재장전 |
| Esc | 일시정지(남은 시간이 멈춤, 화면을 클릭하면 이어서 진행) |

총알은 화면 가운데 조준점 쪽으로 나갑니다. 적을 맞히면 조준점이 잠깐 빨갛게 바뀝니다.

### 적 봇

| 무기 | 색 | 행동 | 소리 |
| --- | --- | --- | --- |
| 소총 | 빨강 | 순찰하다가 중간 거리에서 교전 | 사격음, 탄창 교체음 |
| 산탄총 | 주황 | 가까이 다가와 한 발의 피해가 큼 | 사격음, 펌프 장전음 |
| 저격총 | 보라 | 높은 곳에 자리 잡고 멀리서 사격 | 사격음, 볼트 장전음 |
| 칼 | 검정 | 총소리 없이 빠르게 접근 | 휘두르는 소리 |

모든 봇은 이동할 때 바닥 재질에 맞는 발소리를 냅니다. 플레이어가 총을 쏘면 40 m 안의 봇이 그쪽으로 다가옵니다. 처치된 봇은 10초 뒤 플레이어 화면 밖의 부활 지점에서 다시 나타납니다.

### 10초 대응 시간

봇은 플레이어를 처음 공격한 뒤 **10초 동안 일부러 빗나가게** 쏘거나 헛휘두릅니다. 빗나간 총알은 플레이어 근처를 스치는 소리와 벽에 맞는 탄착음을 냅니다. 이 소리를 듣고(또는 SoundCompass 표시를 보고) 돌아보거나 엄폐할 시간을 주기 위한 규칙입니다. 10초가 지나면 실제로 맞히기 시작하고, 봇이 플레이어를 놓쳐 순찰로 돌아가면 10초가 다시 시작됩니다.

### 맵

| 맵 | 특징 | 바닥 | 환경음 |
| --- | --- | --- | --- |
| 연습장 | 2층 건물 하나와 봇 2명(소총, 칼) | 콘크리트 | 바람, 먼 차량 소음 |
| 도심 골목 | 2~3층 건물 5채, 계단, 창문, 옥상, 골목 | 콘크리트 | 바람, 먼 차량 소음 |
| 창고 실내 | 지붕 덮인 실내, 중이층, 캣워크, 선반 줄, 사무실 | 금속 | 환풍기, 기계음 |
| 야외 숲 | 언덕, 감시탑, 절벽, 2층 오두막, 나무 | 흙 | 바람, 새소리 |

본 맵 3개는 모두 80 × 80 m이고, 봇 4명과 상자 6개로 조건이 같습니다. 맵마다 배경음악이 따로 있습니다.

### 화면에 보이는 것

화면에는 조준점, 체력, 남은 시간, 모은 상자 수, 탄약만 표시됩니다. 피격 방향 표시, 미니맵, 레이더, 적 위치 표시는 일부러 넣지 않았습니다. 이런 정보가 있으면 SoundCompass 없이도 적의 위치를 알 수 있어 비교가 무의미해지기 때문입니다. 같은 이유로 화면 밖 봇의 탄도선은 그리지 않습니다.

## 소리

### 출력 방식

| 방식 | 설명 |
| --- | --- |
| 바이노럴 스테레오 | HRTF로 소리의 3D 위치를 표현합니다. 헤드폰 기준입니다. |
| 7.1 채널 | Windows 소리 설정에서 출력 장치를 7.1로 바꾼 뒤 게임 페이지를 열거나 새로 고칩니다. 장치가 8채널을 지원하지 않으면 스테레오로 몰래 바꾸지 않고, 시작 단계에서 안내 문구를 띄운 채 멈춥니다. 높이 스피커가 없으므로 위아래 정보는 가림과 거리로만 전달됩니다. |

### 가림

벽, 바닥, 닫힌 문이 소리를 가리면 음량을 35%로 줄이고 1,500 Hz 저역 통과 필터를 0.15초에 걸쳐 적용합니다. Unreal 버전 SoundCompass의 설정과 같은 값입니다. 그래서 위층에서 나는 발소리는 둔하게 들리고, 창문이나 계단으로 트인 곳에서는 또렷하게 들립니다.

### 음원

음원은 `public/audio`에 있으며, CC0 원본과 로컬 ComfyUI의 Stable Audio 3로 만든 소리입니다. 출처는 [public/audio/CREDITS.md](public/audio/CREDITS.md)에 정리했습니다.

소리를 다시 만들려면 ComfyUI를 켠 뒤 다음을 실행합니다. `--only`로 일부 소리만 지정할 수 있습니다.

```powershell
& "C:\Users\Home\AppData\Local\Comfy-Desktop\ComfyUI-Installs\ComfyUI\ComfyUI\.venv\Scripts\python.exe" -X utf8 tools/audio_build.py --force --only knife_swing
```

## 결과 CSV

라운드가 끝나면 Chrome 다운로드 폴더에 `<참가자ID>_<맵>_<날짜-시각>.csv` 파일이 저장됩니다. UTF-8(BOM 포함)이라 Excel에서 한글이 깨지지 않습니다. 다운로드가 막혔거나 파일이 보이지 않으면 결과 화면의 **CSV 다시 저장**을 누릅니다.

| 열 | 내용 |
| --- | --- |
| participant_id | 참가자 ID |
| condition | 시작 화면에 입력한 조건 이름 |
| map | urban, warehouse, forest |
| audio_output | binaural 또는 7.1 |
| started_at | 라운드 시작 시각(현지 시각과 UTC 오프셋, 예: `2026-12-01T19:20:30+09:00`) |
| crates | 모은 보급 상자 수 |
| kills | 처치 수 |
| deaths | 사망 수 |
| damage_taken | 받은 총 피해 |
| surprise_hits | 기습 피해 횟수: 피격 순간 공격한 적이 화면 밖에 있었거나 벽·바닥에 가려 보이지 않았던 횟수 |

CSV에는 입력한 값이 그대로 기록되지만, Excel은 일부 값을 바꿔 보여 줍니다.

- 조건 이름을 `=`, `+`, `-`, `@`로 시작하지 마세요. 수식으로 읽혀 `#NAME?`이 됩니다.
- 참가자 ID `01`은 Excel에서 `1`로 보입니다. `P01`처럼 문자로 시작하는 ID를 권합니다.

## 조정할 수 있는 값

난이도와 규칙은 [src/config.js](src/config.js)에서 바꿉니다.

| 값 | 기본값 | 의미 |
| --- | --- | --- |
| `ROUND_SECONDS` | 180 | 본 라운드 길이(초) |
| `PRACTICE_SECONDS` | 90 | 연습 라운드 길이(초) |
| `BOT_GRACE_S` | 10 | 봇의 첫 공격 뒤 빗나가는 시간(초) |
| `BOT_RESPAWN_SECONDS` | 10 | 봇 부활 대기 시간(초) |
| `BOT_REACTION_S` | 0.5 | 봇이 플레이어를 본 뒤 쏘기까지 걸리는 시간(초) |
| `WEAPONS` | 표 참고 | 무기별 피해량, 발사 간격, 탄창, 사거리, 탄 퍼짐 |

현재 피해량은 플레이어 소총 25, 봇 소총 8, 산탄총 45, 저격총 50, 칼 25입니다. 마우스 감도는 [src/player.js](src/player.js)의 `MOUSE_SENS`(기본 0.0022)입니다.

## 개발

| 명령 | 용도 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm test` | 테스트 실행 |
| `npm run build` | `dist`로 배포용 빌드 |

| 폴더 | 내용 |
| --- | --- |
| `src/` | 게임 코드(플레이어, 봇, 물리, 길찾기, 라운드, 결과 CSV) |
| `src/audio/` | 오디오 엔진, 가림, 7.1 스피커 계산, 소리 목록 |
| `src/maps/` | 맵 데이터와 건물·계단·플랫폼을 만드는 도우미 |
| `tools/` | 음원 생성·가공 스크립트 |
| `tests/` | Vitest 테스트 |

three.js로 그리고, Rapier로 충돌과 캐릭터 이동을, recast-navigation으로 봇의 길찾기를, Web Audio로 소리를 처리합니다.
